# Dashboard Superstore - Análise de Vendas
## Objetivo
Este projeto analisa dados de vendas de uma loja fictícia (Superstore), mostrando insights sobre vendas, lucro e descontos por região, categoria e segmento.

## Ferramentas Utilizadas
- Microsoft Excel
- Tabelas dinâmicas e gráficos
- Exportação para PDF

## Descrição
O dashboard foi criado a partir dos dados disponibilizados e organizado com filtros interativos e gráficos. Após a finalização, uma versão em PDF foi gerada para facilitar a visualização e o compartilhamento.

## Arquivos
- `dashboard_superstore.pdf`: Versão estática do dashboard.
- `Vendase.xlsx`: Arquivo original com os dados e filtros interativos.

## Insights Principais
- A região Oeste dos Estados Unidos é a mais lucrativa.
- A Categoria de onde vem o maior lucro é a de Mobília.
- O segmento mais lucrativo é o do consumidor.
